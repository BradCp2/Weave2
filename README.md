# Weave2

Weave2 is a locally hosted version control system developed in C++20, inspired by Git's architecture. 
It aims to provide efficient repository management, revision tracking and branching capabilities through a modular command-line interface. 
The project also incorporates asynchronous background processing and event-driven programming.
